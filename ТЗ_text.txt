
Техническое задание для Frontend-разработчика (Панель управления Next.js)
Проект: Стоматологическая клиника — Административная панельСтек: Next.js 19, TypeScript, Tailwind CSS , React Hook Form + Zod, TanStack Query (React Query), Axios, Recharts (для графиков)Коммуникация: REST API (FastAPI) — все запросы с JWT-токеном (роль admin)
1.1. Архитектура Next.js
App Router — все страницы в /app.
Смешанный рендеринг:
Страницы списков (пациенты, записи) — SSR (Server-Side Rendering) для SEO(зачем SEO нужно, скорее всего для админки плевать)  и быстрой загрузки.
1.2. Аутентификация и авторизация
Логин: Отдельная страница /login — форма с телефон/пароль (для сотрудников).
JWT-токен хранится в httpOnly cookies (безопаснее, чем localStorage).
Middleware проверяет:
Наличие токена.
Роль admin в payload.
Если нет — редирект на /login.
Refresh token обновляется автоматически (axios interceptor).
ОБЯЗАТЕЛЬНО нужно добавить историю входа и выхода , нужно добавить по типу сессии или смены , чтобы точно знать кто ответственен на данный момент за пуш уведомления, за записи и работу с клиентами.

По дате (выбор диапазона).
По врачу (выпадающий список из /admin/doctors).

10. Технические требования
10.1. Управление состоянием
React Query (TanStack Query) для:
Кэширования списков (пациенты, записи, услуги).
Автоматического рефетча при изменении данных.
Оптимистичных обновлений (при удалении/редактировании).
Zustand (или Redux) для:
Глобального состояния (текущий пользователь).
Фильтров (сохранять состояние между страницами).
10.2. Формы
React Hook Form + Zod для валидации.
Пример:
const schema = z.object({  name: z.string().min(3, "Название минимум 3 символа"),  price: z.number().positive("Цена должна быть &gt; 0"),});
10.3. UI-библиотека
Рекомендую  Material-UI (более гибкий).
Компоненты: таблицы, модалки, формы, календарь, селекты.
10.4. Таблицы
Использовать React Table (TanStack Table) для сортировки, фильтрации, пагинации
10.5. Календарь
FullCalendar (React-обертка) для отображения записей по дням.
10.6. Чарты
Recharts для графиков на дашборде.
10.7. Работа с файлами
React Dropzone для загрузки изображений услуг/акций.
Загрузка на сервер: multipart/form-data → POST /admin/upload (бэкенд сохраняет в S3 или локально).

13. Безопасность
JWT в httpOnly cookies (защита от XSS).
CSRF-защита (опционально, но рекомендуется).
Rate Limiting на бэкенде для /admin/auth/login (5 попыток в минуту).
Роли: Только admin имеет доступ к админке (проверка в middleware).

15. Дополнительные пожелания
Адаптивность: Админка должна нормально выглядеть на планшетах (не только десктоп).
Темная тема: Переключатель (опционально).
Аудитория: Поддержка прав доступа (например, администратор и менеджер с разными правами) — можно отложить на будущее.
Экспорт: Кнопка "Экспорт в CSV" для списков пациентов и записей.
Уведомления внутри админки: При новой записи показывать toast-уведомление (через WebSockets или polling).
